# 레퍼런스 10개 분석과 네 가지 디자인 시안

2026-11-10 사용자가 공유한 Pinterest 링크 10개를 대상으로, 각 핀의 공개 이미지와 메타데이터를 확인했다. 아래 분석은 이미지에서 관찰한 특징과 이번 시안을 위한 해석이다. 사용자가 해당 특징 전부를 선호한다고 단정하거나 [개인 디자인 원칙](../../docs/design-principles.md)에 확정 취향으로 추가하지 않는다.

## 먼저 확인한 공통점

- **활자와 이미지의 크기 차이가 크다.** 큰 제목이나 제품·인물 한 장면이 먼저 보이고 작은 설명이 뒤따른다. 모든 요소가 같은 무게가 아니다.
- **주인공이 명확하다.** 건축·제품·인물·재질 중 하나가 화면의 넓은 면적을 차지한다. 작은 요소를 많이 채워 시선을 얻는 방식과 다르다.
- **색의 수보다 관계가 중요하다.** 무채색 지면과 강한 유채색 이미지, 같은 색의 배경과 제품, 따뜻한 종이와 적색처럼 색의 면적·온도·명도 관계가 분명하다.
- **웹 화면과 인쇄 지면의 경계가 섞인다.** 거대한 하단 로고, 잡지의 열과 캡션, 포스터의 활자 대비를 화면에 가져온다.

이 공통점이 모든 핀에 똑같이 적용되지는 않는다. 예를 들어 Panora는 반복 카드가 핵심이며, 주황색 제품 화면은 둥근 UI를 사용한다. 눈에 띈 레퍼런스라는 사실이 모든 구성 요소에 대한 승인이라는 뜻은 아니다.

## 수정 기준: 조합보다 원본의 위계부터

첫 시안은 원본을 느슨하게 해석했다. 특히 주황색 제품의 산세리프를 큰 명조로 바꾸고, 스포츠 포스터의 인물 중첩을 사각 사진으로 바꾼 것은 원본의 핵심 위계를 벗어났다. 이번 수정은 여러 핀을 섞기 전에 **각 시안의 주 기준 하나를 정하고 크기·위치·활자·겹침부터 맞추는 것**에 집중했다.

| 시안·주 기준 | 첫 시안의 문제 | 수정본의 구도·조판 | 같다고 주장하지 않는 부분 |
| --- | --- | --- | --- |
| [Forma / 건축](./reference-house.html) · 01 Hotle | 중간 크기 한글 제목 다음에 평면 건축 SVG가 이어짐 | 폭을 거의 채우는 가는 영문 제목, 사진과 제목의 전후 중첩, 작은 상단 정보, 다음 지면의 큰 문장·작은 설명 | 원본 사진·서체 미사용. 대체 사진은 흰 건물의 낮 장면으로 검정 외벽·저녁 조명과 다름 |
| [담 / 조명](./reference-object.html) · 07 주황 제품 | 탁한 주황과 큰 명조가 제품보다 앞섬 | 채도 높은 주황 명암, 작은 흰색 산세리프 제목 왼쪽·제품 중앙·작은 정보 오른쪽 | 패딩 대신 새 SVG 조명. 원본 서체 미확인. 모바일 배치는 별도 대응 |
| [Fold / 편집](./reference-exhibition.html) · 03 SwissBrut | 코발트 그래픽과 한글 두 열 제목으로 다른 스타일이 됨 | 인물/흰 지면 1:1, 오른쪽 아래 대형 단어, 넓은 은색 재질 그래픽, 검정·회색의 대형 수직 목록 | 인물·사진·브랜드·문구는 대체. 금속 이미지는 사진이 아닌 새 SVG |
| [후반전 / 스포츠](./reference-sport.html) · 10 PUSH. | 사각 사진·옆글·큰 숫자로 원본의 중첩이 사라짐 | 세로 종이 지면, 긴 적색 압축 활자, 그 앞의 인물 컷아웃, 작은 분산 문구·인쇄 질감 | 복싱 선수 대신 기존 CC0 축구 사진. 원본 서체 미확인, 수동 윤곽 마스크 |

전체가 가상 기획이며 실제 브랜드의 실적·행사·판매 기능을 암시하지 않는다. 일치한 원리와 대체된 자산을 구분하며 **픽셀 단위 동일본이나 원본 디자인 복제본으로 표시하지 않는다.**

## 폰트·크기·위치 확인

### 실제로 확인한 원본 폰트

03은 [SwissBrut 공식 마켓플레이스](https://www.framer.com/marketplace/templates/swissbrut/)가 연결한 [공개 프리뷰](https://swissbrut.framer.website/)에서 `Brut` 제목의 계산된 스타일을 확인했다. 1440px 뷰포트에서 다음과 같다.

| 항목 | 원본의 계산된 값 | 수정본 적용 |
| --- | --- | --- |
| 서체 | Be Vietnam Pro | 같은 서체의 로컬 폰트 포함 |
| 굵기 | 900 | 900 |
| 크기 | 291.2px | `20.22vw`, 1440px에서 약 291.17px |
| 행간 | 232.96px, 글자 크기의 .8 | .8 |
| 자간 | -16.016px, 글자 크기의 -.055 | -.055em |

원본과 글자 자체가 달라 단어 전체의 폭은 같지 않다. 공개 프리뷰와 핀의 캡처 시점·화면 크기가 동일하다고도 보장하지 않는다. 나머지 원본의 서체명은 확인하지 못했다. 건축·제품은 Arial/Helvetica 계열, 스포츠는 로컬 Impact와 세로 비례 조절을 사용한 **근사**다. 이를 원본 서체로 표기하지 않는다.

### 수정본의 비율 설정

아래는 원본 CSS를 추출한 수치가 아니라, 실제 이미지를 비교해 정한 **이번 구현의 수치**다.

- 건축 제목: 컨테이너 폭의 35% 글자 크기, 굵기 400, 자간 -.075em. 실제 단어 폭·사진과의 겹침을 브라우저에서 확인한다.
- 조명 제목: 데스크톱 `3.8vw`, 30–65px 범위. 제품 중앙 배치와 작은 좌우 글을 유지하며 작은 화면에서는 정보를 아래로 옮긴다.
- 편집 첫 지면: 인물과 흰 지면의 폭 1:1, 높이는 지면 폭의 57.4%. 큰 단어는 오른쪽 아래, 다음 재질 그래픽은 전체 폭. 검정·회색 분야명은 `20.22vw`의 수직 목록이다. 회색은 원본보다 짙게 해 큰 글자의 대비를 보존했다.
- 스포츠 지면: `736:1042` 세로 비율. 제목 `46cqw`에 세로 1.7배 비례, 인물 레이어는 제목 앞에 놓는다. 작은 글은 모바일에서 최소 8px로 제한하며 주요 설명·출처는 포스터 아래에 읽을 수 있는 크기로 다시 제공한다.

배색도 원본 공식 토큰을 확보한 것이 아니다. 건축의 회녹색 `#E8EEE8`·먹색 `#111512`, 제품의 주황 명암 `#FF9808`–`#99400C`, 편집의 흰색 `#FAFAFA`·검정 `#080808`, 스포츠의 종이 `#E9E3D1`·적색 `#B52E21`은 이번 수정본의 값이다.

## 공통 적용 기준

- [AI 티 방지 규칙](../../content/design-cautions.md)과 [개인 디자인 원칙](../../docs/design-principles.md)을 먼저 참고했다.
- 반복적인 박스형 구성, 좌측 세로줄 강조, 장식용 대각선 화살표를 넣지 않는다.
- 레퍼런스에 있는 카드·알약 버튼·브랜드·문구·사진을 관성적으로 따라 하지 않는다.
- 한국어 본문은 시스템 글꼴로 조판한다. Fold의 영문 제목·대형 분야명만 실제 확인한 Be Vietnam Pro 900을 사용한다. Impact가 없는 환경의 스포츠 제목은 인상이 달라진다.
- 구도 비교를 위한 정적 HTML/CSS다. 상단 네 시안 간 이동, 본문 바로가기, 제작 노트 펼침, 조명 시안의 본문 이동은 실제로 작동한다. 가짜 구매·예약 버튼은 없다.
- 스크립트·원격 폰트 의존·자동 모션은 없다. 사진·폰트는 로컬 파일이다. 건축 사진의 출처·라이선스는 사용자가 직접 여는 외부 링크다.

## 검증 기록

2026-11-10 수정본을 Chromium에서 다시 검증했다. 아래는 초기 시안의 검사 결과를 재사용한 것이 아니다.

- 원본 이미지와 수정본을 736px 폭으로 비교했다. 원본의 홍보 이미지 바깥 여백과 수정본의 시안 탐색 바는 동일한 UI가 아니므로, 그림 전체가 아닌 내부 지면의 비율을 구분해 관찰했다.
- 320·390·736·768·1440·2560px × 네 시안, **24개 조합**에서 가로 넘침·깨진 사진·JavaScript 예외·자동 HTTP 요청이 없었다. 모바일·736px 렌더링도 이미지로 확인했다.
- 건축 제목의 실제 글자 영역은 지면 폭의 **88.0%**다. 사진이 제목 앞에 겹치는 구조도 렌더링으로 확인했다.
- 1440px에서 조명 제목은 **54.72px**, 최장 행은 지면 폭의 **18.2%**다. 제품이 제목보다 큰 위계와 중앙 배치를 확인했다.
- Fold는 로컬 폰트 로딩을 확인했다. 1440px에서 제목 **291.168px**, 행간 **232.934px**, 자간 **-16.0142px**다. 인물/흰 지면의 폭은 1:1이다. 모바일 설명과 제목의 겹침을 수정했다.
- 스포츠 제목의 실제 글자 영역은 포스터 폭의 **76.0%**, 지면 비율은 **736:1042**다. 사각 사진 구획 대신 인물·공의 절단과 제목 앞 레이어를 확인했다.
- 네 탐색 링크를 실제 클릭해 경로·현재 페이지 표시를 확인했다. 네 시안의 키보드 본문 바로가기, Enter로 제작 노트 열기·닫기, 건축·조명의 본문 앵커 이동도 확인했다. 탐색 링크 높이는 모두 44px 이상이다.
- 주황 영역은 글을 잠시 숨긴 동일 레이아웃의 배경을 캡처하고, 실제 텍스트 행 영역마다 9개 지점의 배경색을 샘플링했다. 여섯 폭에서 18–20개 행을 검사한 최저 대비는 **4.57:1**이다. 이는 샘플링 결과이며 모든 글자 픽셀의 전수 검사는 아니다.
- 단색 팔레트 대비는 건축 먹색/회녹색 **15.64:1**, 스포츠 적색/종이색 **4.85:1**, Fold의 큰 회색 활자/흰색 **3.35:1**이다. Fold 회색은 큰 글자 기준 3:1을 적용했으며 사진·질감 위 전체 픽셀의 적합성을 인증한 것은 아니다.
- `npm run build`, `node --test test/visuals.test.mjs test/protocol.test.mjs`의 **9개 검사**, `npm run verify:package`의 별도 설치·실제 MCP 조회를 확인했다. 사진·폰트·OFL 파일이 설치본과 작업 파일에서 동일한지도 검사한다.
