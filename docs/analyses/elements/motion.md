# 모션 분석 누적 로그

> 예시별 분석 JSON에서 자동 생성한다. 추가·수정은 [분석 등록 안내](<../../recording-analyses.md>)를 따른다. MCP: `design://analysis-logs/motion`.

사용자가 제공한 선호 레퍼런스의 확인·추정·미확인 관찰을 모은다. 근거 원문과 다른 분석 항목은 예시별 보고서에서 확인한다.

## 도트로 만든 두 얼굴 — 밝은 하프톤 모션의 색감·레이아웃·폰트

수정 2026-11-18 · [상세 분석·근거](<../halftone-talking-heads-study.md#motion>)

피사체의 자리와 얼굴 구조는 유지하고 고개 방향과 입 주변 형태를 움직인다.

**움직이는 대상과 경로** · `motion.movement`

- **동작과 안정된 프레이밍** (confirmed): 연속 표본에서 고개 방향과 입 주변 표현은 달라지지만 좌우 배치와 배경은 유지된다. · 근거: motion-frames, overview-frames

**입력 반응과 동기** · `motion.feedback`

- **발화 동기화** (unknown): 음성과 입 모양의 동기화 여부 및 오차를 검증하지 않았다.

**재사용**

- 프레임 전체를 움직이는 대신 인물의 의미 있는 동작만 강조하고, 필요한 경우 정지 대안을 제공한다.

## IMA–HOME — 디스플레이 활자와 중앙 영상이 교대로 주도하는 에이전시

수정 2026-11-18 · [상세 분석·근거](<../pinterest-ima-home-showreel.md#motion>)

가로 활자 프레이밍과 중앙 영상 장면이 변하고, 이후 명도와 이미지 밀도가 바뀐다.

**등장·전환·사라짐** · `motion.transition`

- **영상 도입에서 작업 지면으로** (confirmed): 영상 앞부분에서 인사말의 잘린 위치와 중앙 영상 장면이 달라진다. 이후 비교적 빈 검정 화면을 지나 흰 Latest work가 나오며, 후반에는 Agency와 도시명 화면이 이어진다. · 근거: pin-video

**재사용**

- 인트로의 움직임과 작업 탐색을 분리해 영상을 보지 않아도 콘텐츠에 도달하게 한다.

## Rico Supply — 중앙 프로젝트 컷이 커지며 제목을 가르는 편집

수정 2026-11-18 · [상세 분석·근거](<../pinterest-rico-supply-interactive.md#motion>)

가운데 행을 크게 펼치고 그 앞뒤의 압축된 행을 그대로 보이는 흐름이다.

**등장·전환·사라짐** · `motion.transition`

- **중앙 이미지와 지면의 변화** (confirmed): 영상의 여러 시점에서 다른 중앙 이미지가 크게 보이고, 뒤에서 큰 제목이 드러난다. 밝은 지면 버전과 어두운 지면 버전이 모두 나타난다. · 근거: pin-video

**재사용**

- 전환 효과가 없어도 각 항목의 제목·이미지·링크가 식별되는 목록을 먼저 만든다.

## Trionn — 작업 썸네일이 원근을 지나 그리드로 모이는 포트폴리오

수정 2026-11-18 · [상세 분석·근거](<../pinterest-trionn-portfolio-motion.md#motion>)

전경 이동과 원근 변화가 프로젝트 그리드 출현으로 연결된다.

**등장·전환·사라짐** · `motion.transition`

- **썸네일 띠에서 2행 목록으로** (confirmed): 초반의 빈 무대와 제목 뒤로 작은 썸네일 띠가 나타난다. 중간에는 전경의 화면들이 커지고 위쪽으로 빠지며, 후반에는 여섯 작업이 3열 2행으로 정리된다. · 근거: pin-video

**재사용**

- 모션의 마지막 상태가 다음 탐색에 필요한 목록을 드러내게 설계한다. 동작 줄이기에서는 해당 목록으로 바로 도달할 수 있게 한다.
