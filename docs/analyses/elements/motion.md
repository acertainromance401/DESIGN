# 모션 분석 누적 로그

> 예시별 분석 JSON에서 자동 생성한다. 추가·수정은 [분석 등록 안내](<../../recording-analyses.md>)를 따른다. MCP: `design://analysis-logs/motion`.

사용자가 제공한 선호 레퍼런스의 확인·추정·미확인 관찰을 모은다. 근거 원문과 다른 분석 항목은 예시별 보고서에서 확인한다.

## 도트로 만든 두 얼굴 — 밝은 하프톤 모션의 색감·레이아웃·폰트

수정 2026-11-18 · [상세 분석·근거](<../halftone-talking-heads-study.md#motion>)

피사체의 자리와 얼굴 구조는 유지하고 고개 방향과 입 주변 형태를 움직인다.

**움직이는 대상과 경로** · `motion.movement`

- **동작과 안정된 프레이밍** (confirmed): 연속 표본에서 고개 방향과 입 주변 표현은 달라지지만 좌우 배치와 배경은 유지된다. · 근거: motion-frames, overview-frames

**입력 반응과 동기** · `motion.feedback`

- **발화 동기화** (unknown): 음성과 입 모양의 동기화 여부 및 오차를 검증하지 않았다.

**재사용**

- 프레임 전체를 움직이는 대신 인물의 의미 있는 동작만 강조하고, 필요한 경우 정지 대안을 제공한다.
