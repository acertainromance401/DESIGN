# 질감 분석 누적 로그

> 예시별 분석 JSON에서 자동 생성한다. 추가·수정은 [분석 등록 안내](<../../recording-analyses.md>)를 따른다. MCP: `design://analysis-logs/texture`.

사용자가 제공한 선호 레퍼런스의 확인·추정·미확인 관찰을 모은다. 근거 원문과 다른 분석 항목은 예시별 보고서에서 확인한다.

## 도트로 만든 두 얼굴 — 밝은 하프톤 모션의 색감·레이아웃·폰트

수정 2026-11-18 · [상세 분석·근거](<../halftone-talking-heads-study.md#texture>)

행을 이루는 점·작은 타원·짧은 획이 얼굴의 내부 명암과 옅은 경계를 형성한다.

**크기·간격·밀도** · `texture.density`

- **표식의 크기와 간격** (confirmed): 미세 표식의 크기와 간격이 고르지 않고, 점 사이로 바탕이 보인다. · 근거: detail-frame

**경계와 소실** · `texture.edges`

- **표식의 경계 소실** (confirmed): 피사체 외곽의 미세 표식은 밝은 바탕에 섞이면서 얼굴 경계를 흐리게 한다. · 근거: detail-frame

**반복 단위와 규칙** · `texture.pattern`

- **표식 제작 방식** (unknown): ASCII 문자, 3D 포인트, 2D 영상 후처리 중 어느 방식인지 원본 소스 없이 확정할 수 없다. · 근거: detail-frame

**재사용**

- 표식의 질감은 이미지에 적용하고 자막은 일반 텍스트로 두어 읽는 기능을 유지한다.

## Blue Current — 수면을 담은 글자와 앞으로 뻗는 수영선수

수정 2026-11-18 · [상세 분석·근거](<../pinterest-blue-current.md#texture>)

글자의 딱 떨어지는 가장자리와 불규칙한 물보라가 다르게 읽힌다.

**경계와 소실** · `texture.edges`

- **단단한 자형 경계와 흩어지는 물방울** (confirmed): 대형 글자는 비교적 선명한 윤곽이지만 일부 물방울은 그 바깥의 바탕까지 흩어진다. · 근거: pin-preview

**재사용**

- 경계를 넘는 잔디테일은 피사체의 성격을 설명할 때만 남긴다.

## Prompt — 흑백 인물 사진을 지면으로 쓴 패션 포스터

수정 2026-11-18 · [상세 분석·근거](<../pinterest-prompt-monochrome-portrait.md#texture>)

매끈하게 반사하는 렌즈, 세부가 보이는 머리카락·피부, 어둡고 넓은 의상 면이 다르게 읽힌다.

**표면과 재질** · `texture.material`

- **반사면과 어두운 천의 대비** (confirmed): 렌즈는 밝고 매끈한 반사면으로 보이며, 옷은 어두운 면과 접힌 주름으로 보인다. 실제 렌즈와 옷 소재는 확인되지 않았다. · 근거: pin-preview

**재사용**

- 색을 줄였을 때 소재 차이는 밝기와 표면의 세부로 보여주고 장식용 질감을 일괄 추가하지 않는다.

## The Edge — 제목 쪽으로 넘어오는 카누

수정 2026-11-18 · [상세 분석·근거](<../pinterest-the-edge-canoe.md#texture>)

바탕은 종이 같은 얼룩과 미세한 결, 사진은 물결의 선과 톤을 보여준다.

**표면과 재질** · `texture.material`

- **종이처럼 보이는 표면** (estimated): 베이지 바탕의 밝기와 얼룩이 고르지 않아 종이 같은 인상이 난다. 실제 종이·필터 사용 여부는 알 수 없다. · 근거: pin-preview

**재사용**

- 인쇄물 인상이 필요한 맥락에 한해 바탕의 결을 절제하고 작은 글자 뒤에서는 잡음을 줄인다.
