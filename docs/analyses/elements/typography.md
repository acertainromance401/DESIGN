## 도트로 만든 두 얼굴 — 밝은 하프톤 모션의 색감·레이아웃·폰트

수정 2026-11-18 · [상세 분석·근거](<../halftone-talking-heads-study.md#폰트-분석>)

중앙 그래픽은 타이포처럼 느껴지는 미세 표식의 질감이 핵심이지만 식별 가능한 문자표나 폰트는 확인되지 않았다. 하단 자막과 앱 UI의 작은 산세리프 계열 글자는 그래픽과 분리해서 본다.

- **얼굴을 이루는 미세 표식**: 미확인 (unknown)
- **하단 영문 자막과 녹화된 앱 UI**: 미확인 (estimated) · 시각적으로 보통 굵기의 자막과 상대적으로 굵은 UI 라벨이 보임; 수치 미확인

**글리프 형태** · `typography.glyphs`

- **ASCII라는 명칭의 한계** (estimated): 이 예시를 설명할 때 도트·하프톤·포인트 클라우드처럼 보이는 얼굴이라고 부를 수 있다. ASCII 유사 인상은 있으나 읽을 수 있는 문자나 원본 문자표를 확인하지 못했으므로 정확한 문자 기반 렌더링 방식으로 확정하지 않는다. · 근거: detail-frame

**기타 관찰**

- **정보용 글자와 이미지용 표식** (confirmed): 얼굴의 미세 표식은 문장을 읽게 하기보다 형태와 질감을 만든다. 하단 자막은 문장 전달을 맡는 별도 층이므로 두 요소의 크기·대비·가독성을 같은 기준으로 평가하지 않는다. · 근거: detail-frame, overview-frames

**서체 패밀리** · `typography.family`

- **정확한 서체 식별** (unknown): 영문 자막은 산세리프 계열처럼 보이나 원본 선언·폰트 파일·렌더링 정보가 없어 정확한 패밀리는 미확인이다.

**굵기와 스타일** · `typography.weight-style`

- **자막과 UI의 시각적 굵기** (estimated): 자막보다 앱 UI 라벨이 굵게 보인다. 수치 웨이트는 확인하지 않았다. · 근거: detail-frame

**재사용**

- 이미지용 미세 표식의 리듬과 정보용 산세리프의 단순함을 독립적으로 추출한다. 실제 문장까지 점묘 처리해 읽기 어렵게 만들지 않는다.
- 모노스페이스를 활용한 유사 대안을 만들더라도 원본 서체를 식별했다는 표현은 피하고 문자별 면적·가독성·라이선스를 확인한다.
- 자막은 한글·영문 혼용과 긴 문장에서도 읽히도록 별도 크기·줄바꿈·대비를 확보한다. 녹화에서 보인 UI 중첩을 재현 기준으로 삼지 않는다.

## Batica — 세 가지 바탕에서 반복한 타이포 스페시먼

수정 2026-11-18 · [상세 분석·근거](<../pinterest-batica-specimen.md#폰트-분석>)

제목은 원에 가까운 내부 공간과 두꺼운 획이 선명한 기하학적 산세리프 스페시먼이다. 실제 폰트 파일과 보조 문구의 서체는 확인하지 않았다.

- **Batica 제목**: 미확인 (estimated)

**글리프 형태** · `typography.glyphs`

- **보여주는 글자** (confirmed): 제목에서는 단층 a, 큰 원형 공간, 네모난 i점이 눈에 띈다. 작은 라벨보다 자형의 차이가 잘 보이는 크기로 제시한다. · 근거: pin-preview

**재사용**

- 자형이 주제일 때 큰 표본을 두되, 구체적인 서체는 라이선스와 실제 렌더링을 확인한 뒤 선택한다.
