## 레이아웃 분석

넓은 내부 무대에서 원근이 다른 작업 화면들이 가운데 제목을 일부 가리고, 전환이 끝나면 평평한 그리드에 모인다.

### 관찰과 근거

**레이어와 겹침** · `layout.layering`

- **전경 썸네일과 제목의 겹침** (confirmed): 큰 헤드폰 프로젝트 화면이 앞쪽에 있고, 다른 화면은 비스듬히 뒤로 이어지면서 DESIGN IN MOTION을 일부 가린다. · 근거: pin-preview, pin-video


### 레이아웃 재사용

- 전환의 중간에는 원근과 겹침으로 작업을 소개하고, 끝에는 읽고 선택할 수 있는 평면 목록을 마련한다.

<a id="text-placement"></a>

## 글자 배치 분석

큰 문구는 작업을 소개하는 무대 뒤쪽에, 작은 정보는 무대의 모서리에 남는다.

### 관찰과 근거

**글과 이미지의 역할 분담** · `text-placement.image-balance`

- **제목과 고정된 듯 보이는 외곽 정보의 분리** (confirmed): 큰 문구는 무대 안에서 위치가 바뀌고 작업 패널에 가린다. 작은 로고와 메뉴 표기는 무대 윗모서리, 짧은 설명은 아래 왼쪽에 따로 보인다. 바깥의 검은 표식과 하단 홍보 문구는 Details.so의 소개 프레임이다. · 근거: pin-preview, pin-video


### 재사용

- 움직이는 장면과 사용자가 계속 찾아야 할 메뉴의 위치를 나누고, 외부 소개 영상의 장식을 사이트 구성으로 착각하지 않는다.


<a id="subject-composition"></a>

## 인물·피사체 구도 분석

인물은 각 작업 이미지 안에 남고, 화면 전체에서 전경 역할을 하는 것은 작업 패널이다.

### 관찰과 근거

**전경·중경·배경** · `subject-composition.depth-layers`

- **가까운 작업과 먼 작업의 크기·각도 차** (confirmed): 중간 프레임에서 우측의 헤드폰 패널이 가장 크고, 다른 작업 패널은 뒤쪽으로 작아지고 기울어진 채 겹친다. 패션 인물은 각 패널 내부에 남아 바깥 무대의 독립 인물처럼 배치되지 않는다. · 근거: pin-preview, pin-video


### 재사용

- 장면 전체의 주 피사체가 인물인지, 인물을 담은 작업 화면인지 먼저 정한다. 작업 화면이 주인공이면 패널의 거리만 바꿔도 깊이를 만들 수 있다.


<a id="motion"></a>

## 모션 분석

전경 이동과 원근 변화가 프로젝트 그리드 출현으로 연결된다.

### 관찰과 근거

**등장·전환·사라짐** · `motion.transition`

- **썸네일 띠에서 2행 목록으로** (confirmed): 초반의 빈 무대와 제목 뒤로 작은 썸네일 띠가 나타난다. 중간에는 전경의 화면들이 커지고 위쪽으로 빠지며, 후반에는 여섯 작업이 3열 2행으로 정리된다. · 근거: pin-video


### 재사용

- 모션의 마지막 상태가 다음 탐색에 필요한 목록을 드러내게 설계한다. 동작 줄이기에서는 해당 목록으로 바로 도달할 수 있게 한다.

## 분위기·스타일·느낌·인상

**확인 범위:** 공개 미리보기와 14.03초 소개 영상의 표본 프레임. Details.so 바깥 프레임과 내부 작업 무대를 구분.

### 분위기

**해석: 빈 무대가 활기를 얻고 정돈으로 돌아온다**

무채색 지면에 작은 유채색 작업물이 들어오고 전경으로 커지면서 활기가 생긴다. 마지막에는 2행 목록으로 정리돼 에너지가 계속 산만하게 남지 않는다.

### 스타일

**해석: 작업 화면 자체를 원근 레이어로 쓰는 포트폴리오**

가는 대형 제목을 배경에 두고 작업 패널의 크기·각도와 겹침으로 앞뒤를 나눈다. 장식으로 전시 공간을 덧붙이기보다 작업 화면이 원근을 만든다.

### 느낌

**해석: 멀리 떠 있던 화면이 가까워졌다가 평면으로 가라앉는다**

작고 기울어진 패널과 크게 보이는 전경 패널의 차가 접근감을 준다. 클립 후반의 바둑판형 정렬은 거리 차를 없애 화면이 다시 평평하게 느껴진다.

- [가까운 작업과 먼 작업의 크기·각도 차](#subject-composition) · 근거: pin-preview, pin-video

### 인상

**해석: 제목을 읽다가 전경 작업에 시선이 옮겨가고 목록에 도착한다**

처음에는 빈 지면의 제목이 기준점이고, 중간에는 겹쳐진 헤드폰 패널이 그 자리를 가져간다. 영상의 마지막 그리드는 다시 여러 작업을 동등하게 훑을 수 있는 상태로 보인다.

## 활용 방안

### 작업물을 먼저 소개한 뒤 바로 탐색하는 포트폴리오 입구

- 연결한 해석: 분위기, 스타일, 느낌, 인상
- 목표: 다양한 작업의 존재를 보여 주고 같은 흐름에서 읽기 쉬운 목록으로 안내한다.
- 유지할 것: 도입에만 앞뒤 거리와 크기 차를 쓰고, 종료 상태에는 작업명·링크가 있는 일반 그리드를 남긴다.
- 바꿔도 되는 것: 패널 수와 이미지 종횡비는 실제 콘텐츠에 맞추고 작은 화면이나 동작 줄이기에서는 중간 연출을 생략한다.
- 피할 조건: 작업명 탐색이나 키보드 접근이 우선인 화면에서 원근 장면을 거쳐야만 목록에 도달하는 구조를 쓰지 않는다.
- 검수: 애니메이션을 끄거나 건너뛰어도 같은 작업을 찾을 수 있는지, 포커스된 링크가 겹친 패널에 가리지 않는지 확인한다.

## 취향과 디자인 결정

### `foreground-crosses-type` · `layout.layering` · 선호 후보

- **분석자 해석**: 프로젝트가 제목 앞을 통과하는 전환이 정적인 썸네일 목록과 다른 깊이를 만든 점이 선호에 기여했을 수 있다.
  - 맥락: 작업 화면 자체를 시각 피사체로 쓰는 포트폴리오 도입.
  - 디자인 결정: 작업을 소개하는 구간에만 원근과 겹침을 주고, 최종 탐색 목록은 읽기 쉽게 남긴다.
  - 상충·검수: 동작 줄이기와 작은 화면에서는 중간 레이어를 생략할 수 있어야 한다.
