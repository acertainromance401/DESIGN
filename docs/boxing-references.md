# 복싱 레퍼런스별 시안

공유한 세 정적 이미지를 각각 확인하고, 아래처럼 서로 다른 구도로 해석했다. 원본 파일·문구·로고·인물 사진은 저장하거나 복제하지 않았다. 사진 대신 직접 작성한 SVG 일러스트를 사용하므로 사진 합성의 사실성과는 차이가 있다. 세 HTML 모두 외부 이미지·폰트·JavaScript 의존성이 없고 대각선 화살표를 사용하지 않는다.

## Overhead

- [첫 번째 링크](https://pin.it/xU8qUGlzA) / [정식 핀](https://www.pinterest.com/pin/932456297873976480/)
- [오버헤드 HTML](./boxing-overhead.html), MCP ID `boxing-overhead`.
- 참조: 위에서 내려다본 링, 붉은 로프와 청회색 매트, 비스듬한 큰 글자, 오른쪽 아래의 작은 인물.
- 적용: 가상 공개 연습 포스터. 링과 가드 자세를 직접 그렸고 한글 제목·일시·하단 안내를 별도로 구성했다.
- 비스듬한 제목은 정적인 지면 구성이다. 장식용 화살표나 실제 모집 기능은 없다.

## Vintage

- [두 번째 링크](https://pin.it/6q0YJIbJS) / [정식 핀](https://www.pinterest.com/pin/39547302974134220/)
- [빈티지 HTML](./boxing-vintage.html), MCP ID `boxing-vintage`.
- 참조: 따뜻한 종이색, 붉은 대형 제목, 제목 앞으로 겹친 가드 자세, 낮은 채도와 인쇄 질감.
- 적용: 가상 훈련 기록 표지. 한국어 제목, 오른쪽 인물, 좌우 짧은 기록, 하단 판본 정보를 구성했다. SVG 노이즈는 고정된 질감이며 움직이지 않는다.
- 실제 훈련 처방·모집·실적을 뜻하지 않는다. 하단 막대는 장식이며 스캔 가능한 바코드가 아니다.

## Arena

- [세 번째 링크](https://pin.it/9O8WG2vtz) / [정식 핀](https://www.pinterest.com/pin/797418677813974005/)
- [아레나 HTML](./boxing-arena.html), MCP ID `boxing-arena`.
- 참조: 긴 세로 비율, 상단 조명과 청록 안개, 중앙의 흰 제목, 두 팔을 든 인물 뒷모습, 붉은 글러브.
- 적용: 가상 복싱 단편 표지. 빛과 군중은 SVG 그라디언트·패턴으로 그렸고 인물은 제목 아래에 겹쳤다.
- 실제 인물·선수·영화의 홍보물은 아니다. 정적 참조만 확인했으므로 원본의 애니메이션을 재현했다고 주장하지 않는다.
