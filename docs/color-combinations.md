# 색 조합 비교

[HTML 비교 화면](./color-combinations.html)을 내려받아 브라우저에서 열면 같은 산책 기록 화면을 여덟 가지 색으로 볼 수 있다. 레이아웃과 글자는 같고, 바탕·본문·표면·강조색만 다르다.

느낌은 이 화면에서의 해석이다. 같은 색도 면적, 서체, 사진, 문화적 맥락에 따라 다르게 보인다. 아래 용도는 추천 예시이지 정해진 규칙이 아니다.

구성까지 다른 화면은 [분위기별 HTML 예시](./mood-examples.html)와 [18가지 추가 배색 문서](./mood-examples.md)에 있다. 독서·음악·여행·전시·작업 도구·카페 화면마다 세 조합을 비교한다. 이 문서의 여덟 조합과 합쳐 총 26가지다.

## 조합별 메모

색 코드 순서는 **바탕 / 본문 / 표면 / 강조 / 강조 위 글자**다. 표면은 기록을 묶는 보조 영역, 강조는 큰 숫자 뒤의 색면에 사용했다.

## 앱에 옮길 때

- 먼저 `background`, `text`, `surface`, `accent`, `on-accent`처럼 역할에 연결한다. 버튼·링크·선택·오류를 같은 강조색으로 일괄 교체하지 않는다.
- 이 예시의 일반 텍스트 조합은 WCAG 대비 계산으로 **4.5:1 이상**인지 확인했다. 실제 앱에서는 호버·비활성·오류·포커스와 이미지 위 글자까지 다시 측정해야 한다.
- 다크 조합 두 개는 별도의 팔레트다. 라이트 팔레트의 RGB를 반전한 것이 아니며, 자동 테마 전환 예제도 아니다.
- 숫자 뒤 강조 면적은 여덟 화면에서 동일하다. 배경을 강조색으로 바꾸거나 사진을 넣으면 이 비교와 인상이 달라진다.
- HTML의 기록 값은 고정된 시연 데이터다. 앱 기능이나 저장 동작은 없고, 각 화면 아래의 색 코드만 펼칠 수 있다. 외부 폰트·이미지·스크립트를 사용하지 않았다.

이 자료는 문서용 시각 예시다. MCP 패턴 카탈로그에 등록된 예제가 아니므로 기존 138개 범용 패턴 및 대표 웹 예제 10개의 집계에는 포함하지 않는다.

원칙은 [색상·테마 지침](../content/library/color-theming.json), 기존 프로젝트의 팔레트 적용은 [색상, 배경면과 대비](../content/guides/colors-and-surfaces.md)를 참고한다. 더 큰 색면을 쓴 예시는 [야간 러닝 이벤트](./high-energy.html)에 있다.
