# 분위기별 화면과 배색

[HTML 예시 모음](./mood-examples.html)에 구성부터 다른 화면 6개를 만들었다. 화면 위의 배색 선택에서 각각 3가지 조합을 비교한다. 기존 [8가지 색 조합](./color-combinations.md)에 **18가지를 추가해 총 26가지**다.

기존 비교는 같은 화면에 색만 바꾼다. 이번 예시는 서체·정보 밀도·그림·색면의 면적까지 다르다. 서로 다른 화면끼리 비교할 때는 색만의 효과로 해석하지 않는다. 각 화면 안에서 배색을 바꾸면 색의 차이를 따로 볼 수 있다.

표의 색 코드 순서는 **바탕 / 본문 / 표면 / 강조 / 강조 위 글자**다. HTML에서도 선택한 색 코드를 같은 순서로 표시한다. 색을 고르면 해당 화면만 바뀌며 저장하거나 전송하지 않는다.

<a id="reading"></a>
## 조용한 독서 화면

[독서 예시](./mood-examples.html#reading)는 명조체와 짧은 행을 사용했다. 본문 옆의 선에만 강조색을 넣는다. 긴 본문을 작은 글자나 흐린 색으로 만들지 않고, 실제 앱에서는 사용자의 글자 크기 설정을 우선한다.

| 조합 | 색 코드 | 차이 |
| --- | --- | --- |
| 오트밀 + 갈색 | `#F4EDDF` / `#393126` / `#E7DBC7` / `#745135` / `#FFFFFF` | 따뜻한 종이 쪽에 가깝다. |
| 세이지 + 짙은 초록 | `#EFF1E8` / `#303B31` / `#DEE4D6` / `#466246` / `#FFFFFF` | 조금 더 서늘하고 담백하다. |
| 라일락 + 보라 | `#F2EEF7` / `#373047` / `#E3DBEE` / `#65517E` / `#FFFFFF` | 개인 일기나 짧은 글 목록에도 써볼 만하다. |

<a id="music"></a>
## 늦은 밤 음악 화면

[음악 예시](./mood-examples.html#music)는 어두운 바탕 위에 레코드와 파형을 배치했다. 그래픽은 CSS 장식이고 재생 기능은 없다. 밝은 강조색에 어두운 글자를 올리는 조합이다. 실제 플레이어에서는 진행률·볼륨·재생 상태를 장식 파형과 구분해야 한다.

| 조합 | 색 코드 | 차이 |
| --- | --- | --- |
| 먹보라 + 연보라 | `#211A30` / `#F1E9FF` / `#352945` / `#C5A4FF` / `#211A30` | 야간 공연이나 음악 쪽의 인상이 난다. |
| 와인색 + 살구분홍 | `#281A1C` / `#FFECEE` / `#432B30` / `#FFAAA3` / `#281A1C` | 같은 어두운 화면이 더 따뜻해진다. |
| 남청색 + 아이스블루 | `#172632` / `#EAF5FF` / `#293D4D` / `#95D6FF` / `#172632` | 차갑고 또렷하다. 기기 화면에도 써볼 만하다. |

<a id="travel"></a>
## 가벼운 여행 화면

[여행 예시](./mood-examples.html#travel)는 큰 지역명과 둥근 풍경으로 구성했다. 사진 없이 색면을 비교하는 표본이다. 실제 사진을 넣으면 같은 팔레트라도 인상이 달라진다. 풍경 위에 글자를 겹치지 않았다.

| 조합 | 색 코드 | 차이 |
| --- | --- | --- |
| 살구 + 구운 갈색 | `#FFE7D2` / `#403022` / `#F4D1AE` / `#90512C` / `#FFFFFF` | 햇볕이 드는 낮 풍경에 가깝다. |
| 물빛 + 청록 | `#E1F2EF` / `#203E3C` / `#C6E3DC` / `#256762` / `#FFFFFF` | 바다·산책 안내에 어울리는 시원한 조합이다. |
| 버터색 + 올리브 | `#F8F0BD` / `#3B3821` / `#E9DF9E` / `#686025` / `#FFFFFF` | 밝지만 형광색처럼 강하지는 않다. |

<a id="exhibit"></a>
## 선이 강한 전시 화면

[전시 예시](./mood-examples.html#exhibit)는 제목을 세 줄로 쌓고 형태 하나와 날짜를 붙였다. 제목의 압축된 간격은 짧은 전시명용이다. 긴 제목·다국어·큰 글씨에서는 행 수와 간격을 다시 잡아야 한다.

| 조합 | 색 코드 | 차이 |
| --- | --- | --- |
| 석회색 + 붉은색 | `#F5F0E9` / `#292523` / `#E3DBD2` / `#A32D32` / `#FFFFFF` | 붉은 선이 강하게 잡힌다. |
| 회백색 + 코발트 | `#EEEFEB` / `#202A3C` / `#DADFE8` / `#2449A2` / `#FFFFFF` | 좀 더 차갑고 그래픽 포스터처럼 보인다. |
| 웜그레이 + 올리브 | `#E9E8DC` / `#313426` / `#D8D9C5` / `#535C2F` / `#FFFFFF` | 같은 구성에서 색의 존재감이 줄어든다. |

<a id="work"></a>
## 정리된 작업 화면

[작업 도구 예시](./mood-examples.html#work)는 사이드바와 목록으로 밀도를 높였다. 메뉴는 정적 표본이다. 선택된 항목은 색뿐 아니라 밑줄과 굵기로 표시했다. 실제 앱의 오류·진행·완료색은 아래 강조색과 별도로 정의한다.

| 조합 | 색 코드 | 차이 |
| --- | --- | --- |
| 쿨그레이 + 슬레이트 | `#F0F3F5` / `#25313D` / `#DFE6EB` / `#425C77` / `#FFFFFF` | 장시간 보는 업무 화면 쪽에 가깝다. |
| 연민트 + 짙은 초록 | `#ECF5F0` / `#263C32` / `#D8E9DF` / `#32624D` / `#FFFFFF` | 같은 목록이 조금 부드러워진다. |
| 흑연색 + 밀짚색 | `#242628` / `#F1F2EE` / `#363A3C` / `#E7CD81` / `#242628` | 어두운 작업 화면에 노란 포인트를 둔다. |

<a id="cafe"></a>
## 따뜻한 카페 화면

[카페 예시](./mood-examples.html#cafe)는 가게 이름, 메뉴, 가격, 영업시간을 보여준다. 컵은 CSS로 그렸다. 가격은 고정 시연 데이터이며 주문 기능은 없다. 메뉴가 길어지면 가격을 줄이거나 겹치지 않게 별도 행으로 배치한다.

| 조합 | 색 코드 | 차이 |
| --- | --- | --- |
| 우유색 + 코코아 | `#EFE2D5` / `#432D24` / `#E0CABA` / `#70412D` / `#FFFFFF` | 커피·빵 같은 따뜻한 인상이다. |
| 로즈크림 + 체리 | `#F5E4DE` / `#472B2D` / `#E9CCC3` / `#843842` / `#FFFFFF` | 디저트 메뉴 쪽으로 분위기가 바뀐다. |
| 크림옐로 + 말차 | `#EDEBCF` / `#353B26` / `#DDDEB5` / `#57632F` / `#FFFFFF` | 노란 바탕과 녹색 포인트가 식재료를 떠올리게 한다. |

## 검증과 사용 범위

- 2026-11-07 기준, 18개 팔레트의 `본문/바탕`, `본문/표면`, `강조 위 글자/강조`를 각각 계산해 최저 **6.18:1**을 확인했다. 이번 HTML의 글자는 바탕·표면 위 본문색을 사용한다. 강조색은 주로 그림과 선에 사용하고 작업 개수 라벨에서 강조 위 글자를 사용한다.
- 320px·390px·768px·1440px에서 18개 배색 변경, 표시 코드 일치, 가로 넘침을 총 72가지 조건으로 확인했다. 네이티브 `select`의 키보드 포커스 표시도 확인했다. 통합 브라우저 자동화에서 방향키 선택 변경은 확인하지 못했으므로 대상 브라우저에서 수동 확인한다.
- JavaScript 없이도 여섯 화면의 기본 배색은 보인다. 배색 선택은 비활성화하고 안내문과 배색 문서 링크를 제공한다. JavaScript 사용 시 외부 요청·저장·자동 애니메이션은 없다.
- 느낌에 대한 설명은 이 예시의 해석이지 심리학적 보장이나 접근성 인증이 아니다. 기기별 서체, 실제 콘텐츠, 확대, 스크린리더와 앱 상태는 대상 앱에서 추가 검증한다.
- 문서용 예시이며 MCP 카탈로그의 패턴 수·대표 코드 예제 수는 바꾸지 않는다.
- MCP 0.3.0부터 `search_design_visuals`와 `get_design_visual`의 `id=mood-examples`로 조회할 수 있다. `includeSource=true`로 HTML을 받는다. 기존 패턴과 별도인 시각 예시다.

색 역할과 대비 기준은 [색 조합 적용 메모](./color-combinations.md#앱에-옮길-때)와 [색상·테마 지침](../content/library/color-theming.json)을 참고한다.
