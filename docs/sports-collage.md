# 스포츠 사진 콜라주

[HTML 시안](./sports-collage.html)은 흰 여백, 가로 사진 구획, 얼굴 확대, 프레임을 넘어서는 인물 레이어를 조합한 가상 편집물이다. 대각선 화살표와 장식용 움직임은 사용하지 않는다.

## 참고 링크

- [사용자가 공유한 Pinterest 핀](https://www.pinterest.com/pin/706080047875226216/)
- [핀의 정적 이미지](https://i.pinimg.com/736x/fd/ca/44/fdca442b4ce758c04e337c89b6fc0904.jpg)

참고 이미지는 스포츠 동작 사진, 눈 클로즈업과 배경을 제거한 인물을 겹친 세로 포스터다. 저장·재사용 권한이 확인되지 않아 원본 파일은 저장하거나 패키지에 포함하지 않았다. 링크만 기록하며 원본 문구·사진·배치는 복제하지 않는다.

## 사용 사진과 권한

- 파일: [sports-soccer-cc0.jpg](./assets/sports-soccer-cc0.jpg), 2100 × 1500.
- 작가: Keith (Pixabay 사용자 keijj44).
- [Wikimedia Commons 파일·라이선스 설명](https://commons.wikimedia.org/wiki/File:Soccer-1490541_960_720.jpg)
- [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Commons imageinfo 메타데이터에서 작가, CC0와 `Restrictions: personality`를 확인하고 다운로드했다.

사진 원본은 그대로 보관한다. HTML에서 흑백·채도 조정, 확대·크롭과 SVG 윤곽 마스크를 적용한다. 마스크는 머리카락까지 정밀하게 제거한 사진 편집 결과가 아닌 수동 윤곽이다. 하나의 사진을 서로 다른 크기로 재사용했으며 별개의 경기 사진처럼 설명하지 않는다.

CC0는 초상권·상표권까지 허가하는 것이 아니다. 실제 인물이나 팀·브랜드의 추천·후원·실적을 암시하지 않는 디자인 시안으로만 구성했다. 상업 홍보물로 전환하기 전에는 별도의 권리 검토가 필요하다.

## 사용

HTML과 `assets/sports-soccer-cc0.jpg`를 상대 경로 그대로 함께 보관하면 외부 요청 없이 열린다. JavaScript 의존성은 없다. MCP ID는 `sports-collage`이며 HTML 조회만으로 사진 바이너리가 전달되지는 않는다. 사진은 npm 패키지의 `docs/assets/`에 포함된다.
